# LC BIM Resolver · visor web

Sitio estático (compilado) del **BIM Resolver** de Life City BIM Management Hub: tablero gamificado de
incidencias MEP, informes de coordinación (Navisworks / BCF / BIM Vision) y visor IFC (ThatOpen).

- Abrir: https://proyectos-lifecity.github.io/bim-resolver/?project=florentino
- Se conecta al orquestador LC en `http://localhost:8787` (debe estar corriendo en el equipo).
  Para otro servidor: `?api=https://mi-orquestador` (se recuerda en el navegador).
- Misión directa: `&mission=CL107` · clash: `&clash=<id>`

El código fuente está en el repositorio privado `proyectos-LIFECITY/lc-bim-resolver`; este repositorio solo
contiene la compilación publicada en GitHub Pages.
